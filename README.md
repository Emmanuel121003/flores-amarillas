# 🌼 Flores Amarillas · 21 de Septiembre

Animación web de flores amarillas para celebrar el 21 de septiembre, el día de
regalar flores amarillas como símbolo de amistad, alegría y nuevos comienzos.

## Versiones

- **`index.html`** — página de inicio para elegir versión.
- **`primavera.html`** — cielo azul y pétalos flotando (tradición original del hemisferio sur).
- **`otono.html`** — cielo dorado y hojas cayendo (la estación real en México ese día).

Todo está hecho con HTML, CSS y `<canvas>` puro (sin dependencias, salvo las
fuentes de Google Fonts). La animación respeta `prefers-reduced-motion` y se
adapta a pantallas de celular.
